# Тапёр · модули — правила для ИИ-помощника

Это **публичный** репозиторий платных модулей Тапёра. Всё, что попало в `main` на GitHub, сразу видят все.
Код здесь открыт **для проверки** (чтобы любой мог убедиться, что модуль не делает ничего плохого),
а не для свободного использования — см. `LICENSE`.

Ядро Тапёра — отдельный **закрытый** репозиторий `alexshikaka/tapyor-player`. Спецификации, планы и решения
владельца живут там (`docs/PLAN-TWITCH-BOT.md`, `docs/MODULES-LICENSING.md`). Сюда их не копировать.

## Кто владелец и как с ним работать

- Русскоязычный стример, **не программист**. Общаться по-русски, простыми словами.
- **Публиковать (заливать на GitHub) — только по явной команде владельца.** Без команды — только локальные коммиты.
- Сначала макет, потом код — для заметных изменений интерфейса.
- Каждое изменение — коммит с понятным русским сообщением.

## Что здесь НЕ хранить — никогда

- ключи, токены, пароли, cookies, `*.secret.json`, `.env` — только секреты GitHub Actions;
- **закрытый ключ подписи лицензий** — ни здесь, ни в ядре, ни в одном git;
- переписку с ИИ, handoff, карточки сессий;
- аудиты безопасности и списки найденных дыр;
- пути и данные компьютера владельца, адреса облачных функций, идентификаторы облачных каталогов;
- планы монетизации, цены, заметки о конкурентах.

На GitHub включены Secret scanning и Push protection — но это страховка, а не причина расслабляться.
Перед каждой заливкой — сверка с этим списком.

## Что здесь хранить

Код модулей, тесты, `README.md`, `LICENSE` и документацию **для того, кто проверяет код**:
что модуль делает, какие данные и куда отправляет, какие разрешения просит у Twitch.

## Устройство

| Папка | Что там |
|---|---|
| `streamer-pack/` | платный пак стримера |
| `streamer-pack/bot/` | чат-бот Twitch (первый модуль) |
| `streamer-pack/overlay/` | оверлей-плейлист для OBS: `src/` — главный процесс, `page/` — страница, `tests/` |
| `streamer-pack/dock/` | позже |
| `skins/` | оболочки (переедут из ядра к 1.0) |
| `docs/` | устройство модулей и связь с ядром |

Как модуль подключается к ядру — `docs/ARCHITECTURE.md`. **Модуль не лезет во внутренности ядра** — только через
описанный там мост. Если мосту чего-то не хватает — это задача для ядра, а не обходной путь в модуле.

## Ветки и выпуск

- На GitHub только `main`; рабочие ветки — локально.
- Модули выпускаются в релизах **этого** репозитория, теги `<модуль>-vX.Y.Z` (`streamer-pack-v1.0.0`).
- **Никогда не в `tapyor-releases`** — это сломает автообновление ядра.
- Старые релизы и теги не удалять. Откат — только новой версией.

## Проверки

`npm test` — тесты на чистом Node (без Electron и без сети). Логика бота тестируется на поддельном мосте ядра
и поддельном Twitch. Настоящий Twitch и настоящее ядро проверяет владелец руками.
