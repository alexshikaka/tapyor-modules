# Модули Тапёра

Дополнения к [Тапёру](https://github.com/alexshikaka/tapyor-releases) — музыкальному плееру для ПК с заказами
песен от зрителей.

Сам плеер бесплатный и работает без модулей. Модули платные, их код открыт **для проверки**: стримерские функции
работают с твоим аккаунтом Twitch, и ты вправе убедиться, что они не делают ничего лишнего. Условия — в [LICENSE](LICENSE).

## Что здесь

| Модуль | Что делает | Состояние |
|---|---|---|
| **Пак стримера → чат-бот Twitch** | заказы песен командой в чате и за баллы канала, «событие заказов» с розыгрышем | в разработке |
| Пак стримера → док-панель OBS | управление заказами прямо из OBS | позже |
| Пак стримера → оверлей-плейлист | «что играет» и «что дальше» поверх стрима (OBS, источник «Браузер»), стиль «DOS-терминал» | в разработке |
| Оболочки | платные темы оформления | позже |

## Что бот делает с твоим Twitch

- Работает **у тебя на компьютере** и общается с Twitch напрямую — без серверов Тапёра.
- Вход — через официальную страницу Twitch по короткому коду. Пароль Тапёр не видит.
- Токены хранятся зашифрованно на твоём компьютере и уходят только в Twitch. В журнал и лог не пишутся.
- Разрешения, которые бот просит (`streamer-pack/bot/src/twitch/config.js`):

| Разрешение | Зачем |
|---|---|
| `user:read:chat` | читать чат твоего канала — видеть команды заказа |
| `user:write:chat` | отвечать зрителям в чат |
| `moderator:read:followers` | проверять «фолловер не меньше N дней», если ты включил такое правило |
| `channel:manage:redemptions` | создать награду «Заказать песню», ставить её на паузу, отмечать «выполнено» или возвращать баллы |

Больше бот ничего не просит: не видит твою почту, не меняет настройки канала, не банит зрителей.
