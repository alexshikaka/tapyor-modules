# Модули Тапёра

Дополнения к [Тапёру](https://github.com/alexshikaka/tapyor) — музыкальному плееру для Windows с заказами
песен от зрителей.

Сам плеер бесплатный, с открытым кодом и работает без модулей. Пак стримера платный, его код открыт **для
проверки**: бот работает с твоим аккаунтом Twitch, и ты вправе убедиться, что он не делает ничего лишнего.
Условия — в [LICENSE](LICENSE).

## Пак стримера

| Модуль | Что делает |
|---|---|
| **Чат-бот Twitch** | заказы песен командой `!play` и за баллы канала, «событие заказов» с розыгрышем, лимиты, паузы, блокировки, тексты ответов |
| **Оверлей-плейлист** | «что играет» и «что дальше» поверх стрима (OBS, источник «Браузер»): 26 стилей, ник заказавшего |
| **Моушн-оверлей** | карточка трека, которая появляется при смене песни, со своей анимацией у каждого стиля |

Все стили оверлея можно посмотреть вживую на [сайте Тапёра](https://alexshikaka.github.io/tapyor-web/#overlays).

- **Первый месяц бесплатно:** 30 дней со всеми функциями, без карты и без ключа (в Тапёре: «Настройки → Модули →
  Пак стримера» → «Попробовать»).
- Дальше — **$10 один раз**, ключ на 3 компьютера: [купить на GGSel](https://ggsel.net/catalog/product/104388863).
- Пак ставится из Тапёра кнопкой «Установить»: подписанный файл `.tpack` из релизов этого репозитория, подпись
  проверяется перед установкой.

## Как проверить код

- Бот — `streamer-pack/bot/`. Разрешения Twitch — `streamer-pack/bot/src/twitch/config.js` (таблица ниже).
- Оверлеи — `streamer-pack/overlay/`. Страница для OBS только **читает** состояние плеера и ничего не может нажать
  в Тапёре; файлы отдаются по белому списку (`streamer-pack/overlay/src/index.js`).
- Тесты — `npm test` (Node 20+).

## Что бот делает с твоим Twitch

- Работает **у тебя на компьютере** и общается с Twitch напрямую — без серверов Тапёра.
- Вход — через официальную страницу Twitch по короткому коду. Пароль Тапёр не видит.
- Токены хранятся зашифрованно на твоём компьютере и уходят только в Twitch. В журнал и лог не пишутся.
- Разрешения, которые бот просит (`streamer-pack/bot/src/twitch/config.js`):

| Разрешение | Зачем |
|---|---|
| `user:read:chat` | читать чат твоего канала — видеть команды заказа |
| `user:write:chat` | отвечать зрителям в чат |
| `moderator:read:followers` | проверять «фолловер не меньше N дней», если ты включил такое правило |
| `channel:manage:redemptions` | создать награду «Заказать песню», ставить её на паузу, отмечать «выполнено» или возвращать баллы |

Больше бот ничего не просит: не видит твою почту, не меняет настройки канала, не банит зрителей.
