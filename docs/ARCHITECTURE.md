# Как модули подключаются к ядру

Статус: черновик 03.11.2026, до первого подключения бота к ядру. Меняется вместе с ядром.

## Главное правило

Модуль **не лезет во внутренности ядра**. Ядро даёт модулю **мост** — небольшой набор функций и событий,
описанный ниже. Всё, что модулю нужно сверх моста, добавляется в мост в ядре, а не обходным путём.

Так модуль можно проверить отдельно (тесты на поддельном мосте), а ядро не ломается от модуля.

## Пак и манифест

```
streamer-pack/
  manifest.json      { "id": "streamer-pack", "version": "0.1.0", "minCore": "0.30.0",
                       "modules": [ { "id": "bot", "sinceEdition": 1, "main": "bot/src/index.js" },
                                    { "id": "overlay", "sinceEdition": 1, "main": "overlay/src/index.js" } ] }
  bot/
    src/             код главного процесса (Node): Twitch, логика бота
    ui/              раздел в настройках Тапёра
    tests/           npm test — без Electron и без сети
```

Ядро не подключает пак, если его версия ниже `minCore`, и пишет «обнови Тапёр».

## Привратник (лицензия)

Ядро один раз при запуске модуля спрашивает: `core.license.isEnabled('streamer-pack', 'bot')`.
Модуль включён, если редакция лицензии пака (`edition`) не меньше `sinceEdition` модуля: купившие пак 1
владеют своими модулями навсегда и получают их обновления, новые модули пака 2 — отдельная покупка.
- `true` — модуль запускается.
- `false` — модуль не запускается; его раздел в настройках виден бледным, настройки сохранены, плеер работает.

Пока лицензий нет, привратник всегда отвечает `true` (режим разработки). **Других проверок лицензии в коде модуля
нет** — проверка ровно в одном месте.

## Мост: что ядро даёт модулю (главный процесс)

| Функция / событие | Что делает |
|---|---|
| `core.version` | версия ядра |
| `core.log(text)` | строка в лог Тапёра. **Токены и ключи в лог не пишутся никогда** |
| `core.settings.get(key)` / `.set(key, value)` | настройки модуля, в своём разделе `mod.streamer-pack.*` |
| `core.secure.get(key)` / `.set(key, value)` | токены Twitch — зашифрованно (Windows safeStorage), только для этого модуля |
| `core.openExternal(url)` | открыть ссылку в браузере; разрешены только адреса Twitch |
| `core.findOrder(text, opts)` | поиск песни **тем же ранкером, что и для донатов**. `opts.catalogsOnly` — только официальные каталоги (для события), ссылки принимаются всегда. Ответ: `{ level: 'exact' \| 'doubt' \| 'none', track, alts, reason }` |
| `core.checkTrack(track, opts)` | общие правила из «Заказов»: длина, стоп-лист треков и исполнителей, мат, повторы; для ссылок YouTube — минимум просмотров, не трансляция, доступно в стране. Ответ: `{ ok, reason }` |
| `core.orders.add(order)` (async) | заказ в общую очередь по приоритетам из «Заказов». `order.prov`: `twitch-cmd` (ярус «Твич») или `twitch-points` (как платный). Ответ: `{ id, place, etaSec }` |
| `core.orders.remove(id)` | убрать заказ (например, отменён в Twitch) |
| `core.orders.count(prov)` | сколько несыгранных заказов этого вида в очереди |
| событие `order:played(id)` | заказ заиграл — для баллов: «выполнено» |
| событие `order:dropped(id, why)` | заказ не прозвучал (убран, не заиграл) — для баллов: вернуть |
| событие `order:ban(id, minutes)` | стример нажал ⛔ у заказа «Твич» |
| `core.health.set(lineId, state, text, action)` | строки «Чат-бот · …» в стартовом чеклисте; `state`: `ok` / `warn` / `bad` |
| `core.journal.load()` / `.append(entry)` | журнал бота в файл по дням (7 дней), чтобы пережил перезапуск. **Ники и тексты чата — только здесь**, не в логе Тапёра |
| `core.hotkeys.register(id, handler)` | горячая клавиша (например, «открыть событие») |
| `core.http.mount(prefix, handler)` / `.unmount(prefix)` | своя страница на локальном сервере Тапёра (тот же порт, что у панели OBS, по умолчанию 47654). Только `GET`, префикс — одно слово (`/overlay`). `handler(req, res, sub, query)` |
| `core.http.url(path)` | полный адрес страницы для OBS (`http://127.0.0.1:47654/overlay/playlist`) |
| `core.player.on('state', fn)` | снимок плеера: `{ np: { title, artist, cover, pos, dur, playing, at } \| null, next: [...], after: [...] }`. `next` — очередь, `after` — что сыграет фон (волна). Ответ — функция отписки |
| `core.player.on('level', fn)` | общий уровень звука 0…1, ~11 раз в секунду (для осциллограммы) |
| `core.player.want({ state, levels })` | что модулю нужно сейчас. Пока никто не смотрит страницу — `false`, и окно Тапёра ничего не собирает и не шлёт |
| `core.player.coverImage(url)` | обложка своего файла с компьютера (`/lcover/…`): `{ mime, data }` — страница OBS сама её не получит |

Окно настроек модуля (рендерер) общается со своей половиной в главном процессе через один канал
`window.app.modCmd(<id модуля>, command, data)` → `command(cmd, data)` модуля — ядро только передаёт сообщения
(у бота исторически свой `botCmd`).

## Что модуль делает сам

## Оверлей-плейлист (`streamer-pack/overlay/`)

Страница для OBS (источник «Браузер», 1920×1080, прозрачная): что играет, обложка, осциллограмма, прогресс, что дальше.

| Часть | Что делает |
|---|---|
| `src/index.js` | `activate(core)`: страница на `/overlay`, поток `/overlay/events` (SSE), обложка своего файла `/overlay/cover` |
| `src/settings.js` | настройки и их проверка (цвет, угол, сдвиг, размер, до 10 песен, что показывать) |
| `src/feed.js` | что уходит странице: настройки + трек + список «дальше» (с добором из волны) |
| `page/playlist.*` | сама страница, стиль «DOS-терминал»; `?preview=1` — превью в настройках (не считается источником OBS), `?demo=1` — демо-трек |
| `page/dos.js` | раскладка и текст без DOM — проверяется тестами |

Модуль **только читает** плеер: на странице нет ни одной команды, сервер принимает от неё только `GET`.
Шрифт — общий файл ядра `/fonts.css` (Pixelify Sans с кириллицей, лежит внутри Тапёра, интернет не нужен).

## Чат-бот: что модуль делает сам

Ядро про Twitch не знает ничего — всё в модуле:

| Часть | Что делает |
|---|---|
| `twitch/auth` | вход через Twitch по коду устройства (Device Code Flow, без секрета приложения): стример видит код, подтверждает на twitch.tv. Два входа: бот и стример. Обновление входа |
| `twitch/eventsub` | постоянное соединение с Twitch (EventSub WebSocket): сообщения чата, взятые награды, стрим начался/закончился |
| `twitch/helix` | отправка сообщений (ответом на сообщение зрителя), создание и изменение награды, «выполнено»/«вернуть баллы», проверка фолловинга |
| `logic/triggers` | распознать команду или слово заказа |
| `logic/access` | категории зрителей, доступ «нельзя / всегда / по событию», лимиты, пауза, ⛔, блокировки |
| `logic/event` | событие заказов: когда открыть, розыгрыш или «кто первый» |
| `logic/pipeline` | путь заказа: дешёвые проверки → `findOrder` → `checkTrack` → решение по режиму |
| `logic/replies` | тексты ответов с подстановками |

Логика (`logic/*`) не знает ни про Twitch, ни про Electron — только данные на входе и решения на выходе.
Поэтому она целиком проверяется тестами.

## Разрешения Twitch (предварительно, уточнить при подключении)

| Аккаунт | Разрешение | Зачем |
|---|---|---|
| бот (или стример, если пишет от себя) | `user:read:chat` | читать чат канала |
| бот | `user:write:chat` | отвечать в чат |
| стример | `channel:manage:redemptions` | создать награду, поставить на паузу, «выполнено» / вернуть баллы |
| бот-модератор или стример | `moderator:read:followers` | проверка «фолловер не меньше N дней» |

Больше ничего не просим. Пароль Twitch Тапёр не видит; токены хранятся зашифрованно на компьютере стримера
и никуда, кроме Twitch, не отправляются.
